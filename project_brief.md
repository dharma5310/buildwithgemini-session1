# My agent: ChefGemini
One-liner: A conversational agent that helps home cooks find recipes and manage pantry ingredients with a catalog of recipes.

Tool coverage:
- Memory: Remembers user dietary preferences, allergies, and pantry stock
- Tools: Search recipes, add/update recipe, update pantry inventory
- Catalog/UI: Recipe cards and ingredient list tables
- Image gen: Generates dish presentation images for recipes
- Sandbox: Calculates recipe ingredient scaling and total calorie counts

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for recipe scaling calculations
